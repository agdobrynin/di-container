Если в теге элемента коллекции нет указанного имени метаданных, контейнер попытается получить идентификатор элемента из [«метода идентификатора» элемента коллекции по умолчанию](/documentation/tags/using-collecton-key/key-from-method-default.md), а при отсутствии такого метода идентификатора элемента коллекции будет представлен идентификатором контейнера[^ContainerId] этого элемента.
