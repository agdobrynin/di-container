> [!IMPORTANT]
> «Метод ключа» и «метод ключа» по умолчанию должен быть объявлен в PHP классе с модификаторами `public` и `static`. Возвращаемое значение метода – `string`.
>
> В качестве параметров метод принимает два аргумента передаваемые контейнером:
>  - `string $tag` – имя тега.
>  - `array $options` – [метаданные тега](tag-metadata.md).
>
> Эти параметры метода можно использовать построения логики выдачи ключа элемента коллекции.
