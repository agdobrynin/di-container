Параметр `$options` может содержать дополнительные метаданные для устанавливаемого тега представленные массивом.

Ключ массива `$options` это непустая строка, а значение это простой php тип (_`string`, `int`, `bool`, `null` или `array` из этих типов_).

> [!WARNING]
> В параметре `$options` зарезервирован ключ массива `priority.method` – значение типа `string`, для **метода-приоритета**.
> ```php
> $options = [
>   // …
>   'priority.method' => 'staticMethodName' // [!code ++]
> ]
> ```
> **Метода-приоритета** возвращает приоритет для элемента коллекции если не определено значение для параметра `$priority`.
>
> **Метода-приоритета** должен быть объявлен как `public static function` и возвращать тип `int`, `string` или `null`.
>
> В **методе-приоритета** два параметра `string $tag` – имя тега и `array $options` – мета-данные тега, которые передаются контейнером.
>
> Подробнее о [приоритете в коллекции](../collection-priority.md).
