# Приоритет элементов коллекции { #title }

## Обзор { #overview }

Под приоритетом элементов коллекции понимается очерёдность расположения элементов в полученной коллекции. Значение приоритета представлено типами `int`, `string`, `null`.

Для сортировки элементов коллекции используется сравнение значений приоритетов каждого элемента. Сравнение строк происходит как последовательности байтов строк.

**Чем больше значение приоритета, тем выше сервис будет расположен в коллекции.**

Получение приоритета у элемента коллекции в порядке значимости:

1. [Приоритет тега](priority-by-tag.md).
2. [«Метод-приоритета»](priority-by-method.md).
3. [«Метод-приоритета» по умолчанию](priority-by-method-default.md).
