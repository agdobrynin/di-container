Параметр переменной длины `$argument` передает аргументы сеттер-методу.

При объявлении внедрения зависимости в конкретный параметр сеттер-метода, можно использовать [именованные аргументы](https://www.php.net/manual/en/functions.arguments.php#functions.named-arguments).

Параметры сеттер-метода не получившие аргументы будут внедрены контейнером самостоятельно, на основании конфигурации.
