[^BindTag]: Для указания тегов используется метод `bindTag()` доступный в хелпер функциях,
[`diAutowire()`](/documentation/php-definition/di-autowire.md#bindtag), [`diCallable()`](/documentation/php-definition/di-callable.md#bindtag), [`diProxyClosure()`](/documentation/php-definition/di-proxy-closure.md#bindtag), [`diValue()`](/documentation/php-definition/di-value.md#bindtag).

[^BindArguments]: Для передачи аргументов используется метод `bindArguments()` доступный в хелпер функциях,
[`diAutowire()`](/documentation/php-definition/di-autowire.md#bindarguments), [`diCallable()`](/documentation/php-definition/di-callable.md#bindarguments), [`diFactory()`](/documentation/php-definition/di-factory.html#bindarguments).
