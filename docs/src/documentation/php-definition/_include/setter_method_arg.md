Параметр `$arguments` передает аргументы сеттер-методу. При частичном указании как внедрять зависимость в конкретный параметр, указывайте в качестве ключа массива в `$arguments` имя этого параметра.

Контейнер внедрит зависимости самостоятельно в сеттер-метод, на основе конфигурации, включая [объявления через PHP атрибуты](../../attribute-definition/index.md), если в аргументах не указано как внедрять конкретный параметр.

Аргументы сеттер-метода могут принимать хелпер функции такие как `diGet()`, `diValue()`, `diAutowire()` и другие.

Для внедрения скалярных типов зависимостей рекомендуется использовать «[параметры контейнера](../../container-parameters/index.md)».
