[^SetterMethodMutable]: **Мутабельный сеттер-метод** — это метод для изменения значения внутреннего свойства объекта, который модифицирует существующий объект на месте и обычно возвращает `void`.
[^SetterMethodImmutable]: **Иммутабельный сеттер-метод** — это метод, который не изменяет текущий объект, а создаёт и возвращает его новый экземпляр с обновлённым значением.
[^FQCN]: **F**ully **Q**ualified **C**lass **N**ame – полное имя класса, включая пространство имён.
[^TypeHints]: **Type hints** – указание ожидаемого типа данных для параметров метода, например имя конкретного класса или интерфейса.
[^ParameterRuntime]: Параметр «времени исполнения» устанавливает своё реальное значение в уже сформированный контейнер зависимостей (_runtime container_),
и предназначен для корректной конфигурации определений контейнера которые зависят от такого параметра.
[^Parameter]: Параметр контейнера это простой скалярный тип который можно повторно использовать для указания как разрешить зависимость.
[^FactoryPattern]: В некоторых сценариях возникает необходимость для разрешения зависимостей применить шаблон проектирования «фабрика»
чтобы делегировать процесс разрешения специальному объекту – «фабрика».
