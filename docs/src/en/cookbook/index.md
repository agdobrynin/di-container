# Cookbook { #cookbook }

This chapter contains useful tips and tricks for working with the ["kaspi/di-container"](https://github.com/agdobrynin/di-container) dependency container.

This chapter is community-driven; the project authors curate and edit its content.

We invite you to submit your own material via a [pull request](https://github.com/agdobrynin/di-container/tree/docs). The team will review your submissions, provide feedback, and include the best contributions in this chapter.
