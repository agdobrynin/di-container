::: details You can use classes from other container definitions within the arguments.

- `Kaspi\DiContainer\DiDefinition\DiDefinitionAutowire` – PHP class.
- `Kaspi\DiContainer\DiDefinition\DiDefinitionCallable` – injects a dependency by invoking a `callable` type.
- `Kaspi\DiContainer\DiDefinition\DiDefinitionFactory` – [factory](../../factories/index.md) for dependency injection.
- `Kaspi\DiContainer\DiDefinition\DiDefinitionGet` – dependency injection via a reference to a container identifier.
- `Kaspi\DiContainer\DiDefinition\DiDefinitionParameter` – dependency injection from [container parameters](../../container-parameters/index.md).
- `Kaspi\DiContainer\DiDefinition\DiDefinitionParameterRutime` – dependency injection from [runtime container parameters](../../container-parameters/inject_runtime_params.md).
- `Kaspi\DiContainer\DiDefinition\DiDefinitionProxyClosure` – dependency injection via "lazy loading".
- `Kaspi\DiContainer\DiDefinition\DiDefinitionRuntime` – runtime object injection.
- `Kaspi\DiContainer\DiDefinition\DiDefinitionTaggedAs` – dependency injection - [collection by tag](../../tags/index.md).

:::
