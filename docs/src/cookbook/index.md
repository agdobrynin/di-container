# Рецепты { #cookbook }

Эта глава содержит полезные советы и приемы по работе с контейнером зависимостей ["kaspi/di-container"](https://github.com/agdobrynin/di-container).

Глава создаётся силами сообщества. Авторы пакета "kaspi/di-container" курируют и редактируют ее содержание.

Приглашаем вас предлагать свои материалы через механизм [pull-request](https://github.com/agdobrynin/di-container/tree/docs). Участники команды рассмотрят их, предоставят обратную связь и добавят в эту главу лучшие из них.
