# Рецепты { #cookbook }

Эта глава содержит множество полезных советов и приемов по работе с контейнером зависимостей ["kaspi/di-container"](https://github.com/agdobrynin/di-container).

Глава создаётся сила сообщества. Разработчики пакета "kaspi/di-container" курируют и редактируют ее содержание.

Приглашаем вас предлагать свои материалы через механизм pull-request. Участники команды рассмотрят их, предоставят обратную связь и добавят в книгу лучшие из них.
