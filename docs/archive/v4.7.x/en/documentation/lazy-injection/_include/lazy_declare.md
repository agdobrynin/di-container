A PHP class can be declared as "lazy" using the [`diAutowire()` helper function](/en/documentation/php-definition/di-autowire.md) or the [`\Kaspi\DiContainer\Attributes\Autowire` attribute](/en/documentation/attribute-definition/autowire.md) by setting the `$isLazy` parameter to `true`. When a PHP class is declared as lazy, a proxy object is injected, which implements deferred (lazy) initialization of the actual object.
