[^BindTag]: To specify tags, use the `bindTag()` method, which is available in helper functions:
[`diAutowire()`](/en/documentation/php-definition/di-autowire.md#bindtag), [`diCallable()`](/en/documentation/php-definition/di-callable.md#bindtag), [`diProxyClosure()`](/en/documentation/php-definition/di-proxy-closure.md#bindtag), [`diValue()`](/en/documentation/php-definition/di-value.md#bindtag).

[^BindArguments]: To pass arguments, use the `bindArguments()` method, which is available in helper functions,
[`diAutowire()`](/en/documentation/php-definition/di-autowire.md#bindarguments), [`diCallable()`](/en/documentation/php-definition/di-callable.md#bindarguments), [`diFactory()`](/en/documentation/php-definition/di-factory.html#bindarguments).
