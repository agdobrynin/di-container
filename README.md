# Documentation for PHP package "kaspi/di-container".

This documentation use [VitePress](https://vitepress.dev/).

## Development with Docker.

First step – build docker image and install dependencies:

```shell
make build && make install
```

Running development mode:

```shell
make dev
```

and using host from text:
```text
  vitepress 2.0.0-alpha.20  (using vite 8.3.1)

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://172.23.0.2:5173/  eth0
  ➜  press h to show help
```
